# 4aru5h.github.io — Personal Portfolio Mirror

Static web landing page, resume distribution endpoint, and fast CDN mirror for **Aarush Sharma** ([4aru5h.in](https://4aru5h.in)).

## Highlights
- **Fast CDN Delivery:** Hosted on GitHub Pages with zero build dependencies.
- **Responsive Layout:** Mobile-first stylesheet with clean typography.
- **Embedded Resume Asset:** Serves the latest version of `resume.pdf`.
